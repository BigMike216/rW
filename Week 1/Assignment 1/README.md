# Assignment 1 — Sensor Data Analysis

## 1. Aim

To write a C++ program that analyzes 10 distance readings using arrays, loops, and conditional statements.

## 2. Problem Statement

A robot takes 10 distance readings using an ultrasonic sensor. The program must store the readings in an array, find the maximum and minimum values, calculate the average, and count readings below 20 cm and above 100 cm.

The program must use loops and conditional statements without using built-in functions to find the maximum and minimum values.

## 3. Concepts Used

* Arrays: To store the 10 distance readings.
* For loops: To process the readings.
* If statements: To compare values and count readings.
* Arithmetic operations: To calculate the sum and average.

## 4. Algorithm

1. Start.
2. Declare an array to store 10 distance readings.
3. Read the 10 values from the user.
4. Initialize the maximum and minimum using the first reading.
5. Initialize the sum and both counters to zero.
6. Traverse the array using a loop.
7. Update the maximum and minimum values using if statements.
8. Calculate the sum and count readings below 20 cm and above 100 cm.
9. Calculate the average by dividing the sum by 10.
10. Display the results and stop.

## 5. Program Explanation

The program stores the distance readings in an integer array. A loop is used to process each reading and compare it with the current maximum and minimum values.

The sum of all readings is calculated during the same traversal. Two counters are used to track readings below 20 cm and above 100 cm. Finally, the average is calculated and all the results are displayed.

## 6. Result

The program was implemented and executed successfully to analyze the distance readings and calculate the required statistical values.
