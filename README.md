# Robotics Programming

This is my Robotics Programming assignments and
learning documentation from Week 1 to Week 7.

It contains the basic C++ programming, Arduino programming, Tinkercad
circuit simulations, and basic robotics concepts.

## Weekly Work

| Week | Topics                                                   |
|------|----------------------------------------------------------|
| W1   | C++ Arrays, Loops and Basic Problem Solving              |
| W2   | Functions, Line Following Robot and OOP                  |
| W3   | Decimal to Binary Conversion using LEDs                  |
| W4   | Microcontrollers, Potentiometer and Robot Control        |    
| W5   | Potentiometer, Ultrasonic Sensor and Custom Map Function |
| W6   | Ultrasonic Sensor, LED Brightness and PWM                |
| W7   | DC Motor Speed Control using L293D                       |

## Repository Structure

Each week's folder contains the documentation, source code,
and Tinkercad screenshots related to the assignments completed
during that week.

## Learning Outcomes

Through these assignments, I learned about:

- C++ programming fundamentals
- Arrays, loops, functions and classes
- Arduino programming
- Digital and analog input/output
- PWM
- Sensors and actuators
- Ultrasonic distance measurement
- Potentiometer-based control
- LED and motor control
- Tinkercad circuit simulation
